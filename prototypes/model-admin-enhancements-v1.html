模型供应商面板 · 增强 v1 原型

纯前端 mock、无真实请求；样式对齐 plite-tokens 与现有 panel.css。右侧面板可直接操作，左侧按钮可直达各演示点。模型以独立条目管理（v1.1：移除逗号串输入）。

0保存失败可见化（P0 前置修复）

试一试：点「编辑」→ 把 Base URL 改成 https://api.example.com/v1 → 保存 → 表单内出现红色错误条，不再静默关闭。

现状：saveForm 不检查 dispatch 返回值，BASE_URL_NOT_ALLOWED 被吞掉，表现为「新增和修改都无效」。原型改为表单内联错误条 + 错误码展示。

1自动拉取模型列表

试一试：编辑表单里点「⟳ 拉取」→ 搜索 nex → 勾选 → 「加入所选」。命中 models.dev 的模型自动带目录初值（灰色「目录」徽标）。

新增 POST /api/providers/fetch-models：已存供应商按 id 用服务端存储的 key，新建中用表单 key（与 save 同信任边界）。/models 404 时保留手填并明确报错。

2逐模型能力编辑（列表页直达）

试一试：列表页点任意模型 chip → 底部抽屉：token 上下限（支持 1m/200k 简写）、图片输入、思考等级、工具/思考可关/思考耗预算三态开关、单模型重新探测。输出上限 > 输入上限会校验拦截。

补齐 tri-state 字段（tools / canDisableThinking / reasoningEatsBudget）的人工入口；改动来源自动标「人工」徽标；detectedAt 保留。表单内每个模型条目亦可直接进同一抽屉。

3复制配置 / 粘贴导入

试一试：列表页「更多 → 复制配置」→ 左下剪贴板观察窗出现 JSON（不含 Key）；再点「粘贴导入」→ 填入示例 → 解析预览（缺 Key / 白名单警告）→ 导入到表单。

信封格式 polaris-provider-export v1；导入重新生成 id，避免跨实例冲突；单模型粒度复制在模型抽屉底部「复制此模型」。baseURL 不在白名单时导入预览即预警（保存仍会被 SSRF 白名单拦截）。

4查看明文 API Key（带护栏）

试一试：列表页「更多 → 查看 API Key」→ 显示明文 + 10s 倒计时自动隐藏 + 复制按钮 + 审计记录。

新路由 POST /api/providers/reveal-key：登录会话硬门禁；PLITE_ALLOW_REVEAL 环境开关（生产默认 0 时此入口隐藏）；操作写入数据目录审计日志。对 XSS 防线无实质削弱（能拿 session 就能调接口），护栏主要压「意外暴露面」。
