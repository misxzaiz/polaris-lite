本次新增交互标注（v1 原型）

① 消息悬浮操作条 — 悬浮任意消息出现。用户消息：复制 / 编辑 / 重发；AI 消息：复制 / 重新生成。流式生成中自动隐藏。

② 编辑（仅最后一轮） — 截断重答：该轮之后的消息被移除并重新生成。实现版有红色二次确认（原型已演示），且会同步抹掉所有设备上的旧尾巴。

③ 重发（任意历史消息） — 追加新一轮，不破坏历史，零协议改动、成本低。

④ 复制只取正文 — 不含思考块、工具卡、运行提示行。点复制看 toast 提示实际取到的内容。

⑤ 回到底部胶囊 — 滚离底部出现；流式期间显示「有新内容 N 条」。

⑥ 回到顶部 — 长会话快速导航。

⑦ 跳到本条开头 — 长消息（超过大半屏）的操作条里多一个「开头」：点击把这条消息的开头对齐到视口顶部——不是回到会话最顶部；短消息不显示。

⑧ 侧栏悬浮重命名 — 悬浮 ✎ 或双击标题；排序保持现网口径（最后活跃时间）。

⑨ 手机端 — ≤768px（与现网断点一致）自动生效，桌面点「手机预览」可试：侧栏改抽屉（顶部 ☰），触屏无 hover → 操作条常显图标化、侧栏操作恒显。实现版可复用现有 useSessionSwipe 滑切手势。

试试：悬浮任意消息 → 点「编辑」体验截断重答 → 流式期间往上滚看 ⑤ → 滚到顶看 ⑥。
