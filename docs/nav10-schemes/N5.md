# N5 · 图标 Rail + 抽屉（左侧面板导航方案）

> 对应总纲：`docs/nav10-schemes/brief-nav10.md` 路线 N5。
> 参考实现：`D:\space\base\Polaris\src\components\Layout\ToolSwitcher.tsx`（视觉语言与底栏/搜索行样式）、`src/core/SlotLayout.tsx`（四槽壳与移动端抽屉状态机）。
> 与 S1（固定图标栏 + 溢出收纳）的区别：S1 的图标栏**不滚动**，放不下的进「更多」浮层；N5 的 rail **允许纵向滚动**，且每个图标点开的是「该面板的抽屉」（含详情 + 子操作），不是选择列表。

---

## 0. 一句话方案

最左侧放一条 **48px 宽、可纵向滚动的图标 rail**，每个面板占一个图标位；点击图标后在其右侧展开一个 **240px 的面板抽屉**，展示该面板的详情（说明、当前状态、快捷操作、关联会话过滤等），点抽屉内主按钮或再次点击图标才把面板激活到右侧 panel 槽。rail 永远可见，抽屉按需开合。

```
事件顺序（点击 rail 图标）：

用户点击 rail 图标 X
  → 若 X ≠ 当前抽屉面板：drawerPanelId = X，抽屉宽度 0→240px 过渡展开，
    rail 上 X 标记激活态，抽屉内容按 X 渲染
  → 若 X = 当前抽屉面板（再次点击）：收起抽屉（宽度→0），rail 保留激活态
  → 抽屉内点击「打开面板」或双击图标：activePanelId = X，右侧 panel 槽
    切换渲染 X，抽屉保持展开（可继续看详情）或手动收起
```

移动端（≤768px）：rail 变为顶栏下方一条 **44px 横向滚动 chip 条**（或保留竖 rail 挂进现有 sidebar 抽屉），抽屉复用现有 `setDrawer` 机制变成全屏底部抽屉（见 §4）。

## 2. 状态模型与数据流

### 2.1 状态所有权（单一权威）

| 状态 | 所有者 | 说明 |
|---|---|---|
| `railOpenPanelId` | 新组件 `PanelRail` 内部 state | 当前抽屉展示哪个面板（≠ 已激活面板） |
| `activePanelId` | **上提到 shell 级 context**（同 S1/S3 结论） | rail、抽屉、右侧 panel 槽三方共同消费，禁止各自维护 |
| `hoverPanelId` | rail 内部 | hover 预览态（原型可只做 title tooltip） |
| 面板列表 | `host.slots.list('panel')`，`(order ?? 0)` 稳定排序 | 数据源不变，rail 是纯展示层 |

### 2.2 事件流

```
slots.list('panel') 变化（插件装载/卸载）
  → PanelRail 重新渲染 rail 图标列（按 order 排序）
  → 若被卸载的是 railOpenPanelId：收起抽屉
  → 若被卸载的是 activePanelId：激活态回落到列表第一个面板

用户点击 rail 图标 X
  → railOpenPanelId = X（抽屉展开）
  → 抽屉头部/详情/快捷操作按 X 的 manifest 渲染

用户点击抽屉「打开面板」
  → setActivePanelId(X) → panel 槽只渲染 X（SlotOutlet 改受控激活）
  → rail 底栏「当前面板」同步更新

窗口 resize / rail 高度变化
  → rail 自身 overflow-y:auto 自然滚动，无需容量计算（这是与 S1 的关键差异）
  → 激活图标 scrollIntoView({ block:'nearest', behavior:'smooth' })
```

### 2.3 持久化

- 原型阶段：`localStorage['polaris.rail.prefs.v1']` 存 `{ active, drawerOpen }`。
- 宿主落地：按 sidebar-schemes README 的前置条件，统一改走 `cap.config`，key 建议 `polaris.rail.prefs.v1`。

## 3. HTML 骨架层级（class 命名对齐 ToolSwitcher 风格）

ToolSwitcher 的 class 风格：语义块名 + `flex/shrink-0/min-w-0` 等工具类混排、`border-b border-border-subtle` 分区、`rounded-lg/rounded-md`、`text-text-primary/secondary/tertiary` 三级文字。N5 原型沿用该命名气质（kebab-case 块名 + 等价工具类）。

```html
<body>
  <div class="shell" data-layout="four-slot" data-rail-drawer="terminal">
    <!-- ① 图标 rail：最左 48px，独立于 .shell-sidebar 之外的一列 -->
    <nav class="panel-rail" role="tablist" aria-label="面板导航">
      <div class="panel-rail-brand">
        <span class="brand-dot"></span>
      </div>

      <!-- 可滚动区：flex-1 min-h-0 overflow-y-auto，唯一滚动容器 -->
      <div class="panel-rail-scroll">
        <button class="panel-rail-item" role="tab" data-panel-id="chat"
                title="对话" aria-selected="false">
          <span class="panel-rail-icon">◇</span>
        </button>
        <button class="panel-rail-item active" role="tab" data-panel-id="terminal"
                title="终端" aria-selected="true">
          <span class="panel-rail-icon">▣</span>
        </button>
        <!-- …10+ 个，超出高度自然滚动… -->
      </div>

          <div class="panel-drawer-section-title">状态</div>

    <aside class="shell-panel">
      <div class="panel-body" data-active-panel="terminal"><!-- 激活面板内容 --></div>
    </aside>
  </div>
  <script> /* rail/抽屉开合 + 激活上提，~120 行原生 JS */ </script>
```

关键 class 约定：

- `.panel-rail`：`width:48px; display:flex; flex-direction:column; background:var(--bg-elevated,#161923); border-right:1px solid var(--border-subtle,#232733)`。
- `.panel-rail-item`：40px 见方点击区，居中；`.active` 时 `background:var(--accent-soft); color:var(--accent)` + 左缘 2px accent 指示条（`box-shadow: inset 2px 0 0 var(--accent)`）。
- `.panel-rail-scroll`：`flex:1; min-height:0; overflow-y:auto; scrollbar-width:none`（滚动条隐藏，靠 mask 提示）。
- `.panel-drawer`：`width:240px`（收起时 `width:0; overflow:hidden`），`transition:width .16s ease`；内部布局完全复刻 ToolSwitcher：header（`border-b border-border-subtle px-3 py-2`）→ search（`h-8 rounded-lg border border-border-subtle bg-background-surface`）→ body（`min-h-0 flex-1 overflow-y-auto`）→ footer（`border-t border-border-subtle px-3 py-1.5`）。
- grid 布局：`.shell[data-rail]` 改为 `grid-template-columns: 48px auto 240px 1fr 300px` 的变体——抽屉收起时第二列塌缩为 0（用 `grid-template-columns: 48px 0 1fr 300px` 或直接把 rail+drawer 包成一个 flex 容器更简单，原型采用后者：`.rail-drawer-group { display:flex }`）。

## 4. 10+ 面板时的表现与数据流

**表现**：

1. rail 纵向滚动：12~20 个面板时 `.panel-rail-scroll` 出现滚动；顶部 brand 与底部「当前面板」栏固定，中间滚动。滚动条隐藏（`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`），底部 24px 渐隐 mask 提示「下面还有」。
2. 激活跟随：切换到列表深处的面板时，`scrollIntoView({block:'nearest'})` 把激活图标滚入视野；抽屉同步换内容。
3. 抽屉宽度恒定 240px，不随面板数变化；面板增多只影响 rail 滚动长度，**不产生挤压**。
4. hover 预览（增强项）：rail 图标 hover 120ms 后可在抽屉里先显示该面板的轻量预览（名称+描述），300ms 未 hover 不回收——对齐 ToolSwitcher 的 hover 开/收时序；原型阶段可降级为 `title` tooltip。
5. 面板极多（>24）时的二级收敛：rail 底栏上方追加一个「⌕」搜索图标，点开把抽屉临时变成「面板搜索列表」（复用 ToolSwitcher 的搜索行 + 3 列 grid），选中后回到详情抽屉。这是 N5 吸收 N3 的可选拓展，原型可选做。

**数据流**（10+ 面板下的一次切换）：

```
rail 图标点击 X（X 在滚动区中部）
  → railOpenPanelId = X
  → drawer 内容渲染 X 的 manifest（名称/描述/chips/操作）
  → X 图标 .active；若 X 不在可视区，scrollIntoView

抽屉「打开面板」点击
  → setActivePanelId(X)（context 单一权威）
  → SlotOutlet(panel) 受控渲染 X；其余面板不卸载、仅不渲染
  → rail footer「当前面板」文案 = X.name
  → 持久化 { active: X } → cap.config（落地）/ localStorage（原型）

插件列表更新（新增面板 Y）
  → rail 重排（order 稳定排序），Y 追加/插入对应位置
  → activePanelId 不变；若 Y 带 order 抢到首位也不影响当前激活
```

**移动端（≤768px）**：

- rail 变为 `.shell-topbar` 下方 44px 横向滚动条（`overflow-x:auto`，chip = 图标），或整体并入现有 sidebar 抽屉作为第一列。
- 抽屉改为底部 action-sheet（`bottom:0; width:100vw; max-height:70vh; border-radius:12px 12px 0 0; padding-bottom:env(safe-area-inset-bottom)`），复用 `.drawer-mask` 与 `setDrawer` 的 body 锁定。
- 选中「打开面板」后立即 `setDrawer('none')` 收抽屉。

## 5. 优缺点

### 优点

1. **面板数量天然可扩展**：rail 滚动消化任意数量，宽度恒定 48px，结构性不会出现 Tab 挤压变形（对照现状 `slot-tabbar` 平铺的痛点）。
2. **「浏览」与「激活」分离**：抽屉提供详情/快捷操作层，用户可以先看再进，比纯图标栏（S1）多一层信息；rail 常驻使切换路径最短（一次点击见详情，两次点击进面板）。
3. **视觉与 ToolSwitcher 同源**：抽屉头部/搜索行/底栏直接复用 ToolSwitcher 的分区与 token（`bg-elevated`、`border-subtle`、三级文字色、32px 搜索行），评审 D 维度（视觉一致）得分稳定。
4. **对会话列表友好**：rail + 抽屉占宽最多 288px，且抽屉可收起；会话列表保留在原 sidebar 槽，不像 N2 常驻高密度列表那样挤占会话空间。

### 缺点

1. **两级点击成本**：从「看到图标」到「进入面板」需要点抽屉底栏按钮（或双击），比 N2/N3 的直接点选多一步；高频切换用户会嫌繁琐。
2. **图标语义负担重**：rail 只剩图标，10+ 面板时辨识度下降，强依赖 tooltip 与抽屉确认；无图标约定的插件只能用首字母块。
3. **布局改动比 S1 大**：shell 从三栏变四栏（rail 独立成列），`.polaris-lite-shell` 的 grid 与移动端抽屉逻辑都要适配；抽屉与 rail 的联动状态（`railOpenPanelId` vs `activePanelId`）是新的失步风险点。
4. **横向空间占用**：rail(48) + 抽屉(240) 同时展开时比现状 260px 侧栏更宽，窄桌面（<1280px）会挤压消息流；需要「点击消息区自动收抽屉」之类的让位策略。

## 6. 与 ToolSwitcher 的异同对照表

| 维度 | ToolSwitcher（Polaris 顶部） | N5 图标 rail + 抽屉 |
|---|---|---|
| 形态 | 点击/hover 弹出的**浮层**（fixed，360px 宽） | 常驻 **rail 列 + 联动抽屉**（48 + 240px，参与布局流） |
| 触发 | 触发按钮 + hover 120ms / click，Esc/外点关闭 | rail 图标点击；抽屉 ×/再点图标收起 |
| 搜索行 | 有（`h-8`、focus 变 focus-border，过滤全局面板） | 抽屉内可选保留（过滤本面板内容）；>24 面板时可临时变全局面板搜索 |
| 置顶 4 列 grid | 有（`PINNED_LEFT_PANEL_TYPES`，icon 17px + 10.5px 标签） | 无对应物；rail 本身即「全部面板的图标列」，如需置顶可在 rail 顶部加固定分组 |
| 溢出 3 列 grid | 有（overflowItems 紧凑网格） | 无；面板多时 rail 纵向滚动替代溢出列表 |
| 底部「当前侧栏」栏 | 有（activePanelLabel + 关闭按钮） | 有，且拆成两处：rail footer（当前面板名）+ 抽屉 footer（打开面板主按钮） |
| 定位/锚定 | `anchorRef` 计算按钮正下方，clamp 防溢出 | 不需要锚定计算——rail 是布局内固定列 |
| 打开时焦点处理 | click 打开 30ms 后 focus 搜索框；hover 打开不抢焦点 | 抽屉展开不抢焦点；用户点搜索框才 focus（避免打断输入） |
| 数据来源 | `ToolSwitcherItem[]`（id/icon/label/group/onSelect） | `host.slots.list('panel')` + manifest（同源，映射成 rail item） |
| 关闭语义 | onSelect 后立即 onClose，浮层消失 | 激活面板后抽屉**保持展开**（详情继续可见），需显式收起 |
| 激活态 | `item.active` → `bg-primary/10 text-primary` | rail `.active` 同款 accent-soft 底 + 左缘指示条 |
