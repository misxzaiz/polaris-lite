# N1 · ToolSwitcher 浮层（左侧单入口 + 点击弹出全局面板浮层）

> 参考对象：Polaris `src/components/Layout/ToolSwitcher.tsx`（搜索行 / 置顶 4 列 grid / 溢出 3 列列表 / 底部「当前侧栏」栏 / hover 120ms 开 300ms 收）。
> 对应总纲表 N1：平时左侧只显示**当前面板一个入口**，点击弹出 ToolSwitcher 式浮层（搜索 + 置顶 grid + 列表）选择面板。

---

```
│          │             │       │   │          │ └─────────┘ │       │
└──────────┴─────────────┴───────┘   └──────────┴─────────────┴───────┘

事件顺序：
[用户点击 .panel-entry-btn]
  → setSwitcherOpen(true)，openMode='click'
  → 浮层挂载（fixed，锚定入口按钮下方 +6px）
  → 30ms 后 focus 搜索框（对齐 ToolSwitcher：仅 click 打开才 focus，hover 不抢焦点）
[用户输入 query]
  → filteredItems = items.filter(label/description/group 含 query)
  → 置顶区与溢出区各自过滤重排
[用户点选任一 .tool-item]
  → onSelect() 切换当前面板 → onClose() 收浮层
[Escape / 点击浮层外部 mousedown]
  → onClose() 收浮层
```

## 2. HTML 骨架层级（class 命名对齐 ToolSwitcher 风格）

结构落在 polaris-lite 的 `sidebar` 槽（`SlotOutlet slot="sidebar"` 内、会话列表上方），浮层用 `fixed` 定位挂 sidebar 容器内。

```html
<aside class="shell-sidebar">
  <div class="shell-brand">…</div>

  <!-- N1 新增：面板入口 + 浮层 -->
  <div class="panel-nav-root">                       <!-- 包住入口按钮，作为锚定参照 -->
    <button class="panel-entry-btn" aria-haspopup="listbox" aria-expanded="false">
      <span class="panel-entry-icon"><!-- 当前面板 icon --></span>
      <span class="panel-entry-label">文件</span>     <!-- 当前面板名 -->
      <span class="panel-entry-chevron">▾</span>
    </button>

    <!-- 浮层：条件渲染，isOpen 才出现 -->
    <div class="panel-switcher-menu" role="listbox" aria-label="面板切换器"
         style="max-height: min(70dvh, calc(100dvh - 64px))">

      <div class="switcher-header">
        <span class="switcher-header-icon">▦</span>

        <button class="switcher-close" aria-label="关闭">✕</button>

      <div class="switcher-scroll" id="panel-switcher-list">
        <div class="switcher-pinned-grid">              <!-- grid-cols-4 gap-1 -->

            <span class="tool-item-icon">📁</span>

          </button>
```


## 3. 10+ 面板时的表现与数据流

- **数据源**：所有面板来自 `slotRegistry.list('panel')`（polaris-lite 的多实例 panel 槽），每个 entry 映射为 `ToolSwitcherItem` 形状：`{ id: pluginId, icon, label: manifest.name, group, active, onSelect }`。`group` 可按插件 manifest 的 `capabilities`/自定义字段归类（context / changes / run / developer / system 等，对齐 `getToolGroup`）。
- **分区策略（10+ 面板不挤压的关键）**：
  1. 置顶区：按 `PINNED_LEFT_PANEL_TYPES` 语义取最常用 4 个（files / git / browser / terminal 或 lite 里对应插件），4 列 grid，超 4 个仍可滚动 grid 换行；
  2. 溢出区：其余全部进 3 列紧凑 grid，随浮层滚动区 `overflow-y-auto` 垂直滚动——**面板数增加只增加滚动长度，不增加入口视觉负担**；
  3. 搜索：query 对 `label + description + group` 做小写 includes 匹配（对齐 ToolSwitcher `filteredItems`），10+ 面板时用户靠搜索直达；
  4. 空态：两区皆空显示 `switcher-empty`「没有匹配结果」。
- **数据流**：`panel 槽注册/注销事件 → navStore.items 重算（useMemo 依赖 registry 版本号）→ filteredItems 由 query 派生 → 渲染两区`。面板选中后 `onSelect` 调 `slotRegistry` 对应的 activeIndex setter（或新增 `panelNav.setActive(pluginId)`），浮层关闭；sidebar 槽（会话列表）完全不动。
- **移动端（≤768px）**：复用 SlotLayout 的 drawer 机制——入口按钮进 `shell-topbar` 右侧或 sidebar 抽屉顶部，浮层改为 `left:8px right:8px` 全宽底部抽屉。

## 4. 优缺点

**优点**
1. **平时零占用**：sidebar 只多一个单行入口按钮，会话列表空间几乎不被挤压，10+ 面板也不影响常态视觉。
2. **与 Polaris ToolSwitcher 体验完全同构**：搜索/置顶/溢出/底栏四件套直接照搬，用户从 Polaris 迁移零学习成本，视觉一致性得分高。
3. **扩展性最好**：新增面板只是往 items 数组加一条，浮层滚动区自然吸收；分组、置顶、搜索、快捷键都可以后续叠加，不动布局骨架。
4. **天然支持 hover 直达**：可沿用 ActivityBar 的 120ms 开 / 300ms 收 hover 语义（openMode='hover' 不抢焦点），高频用户切换成本极低。

**缺点**
1. **多一次点击/hover 才能见全貌**：面板列表默认不可见，新用户发现性差，需要入口按钮的文案/图标足够明确（如「面板 ▾」）。
2. **浮层遮挡消息流**：打开时盖住 stream 区左缘，若用户边看对话边切面板会有遮挡打断感；需要 mousedown-outside + Escape 的可靠关闭。
3. **状态同步点多**：入口按钮的「当前面板」label/icon、浮层头部 chip、底栏「当前侧栏」三处都要跟 activePanel 联动，漏一处就会出现 UI 不一致。
4. **fixed 定位在移动端/窄窗要额外 clamp**：照抄 ToolSwitcher 的定位 effect 后仍需处理抽屉模式下的坐标基准，原型阶段容易出边界 bug。

## 5. 与 ToolSwitcher 的异同对照表

| 维度 | Polaris ToolSwitcher | N1 方案 |
|---|---|---|
| 触发方式 | ActivityBar「更多工具」按钮 click / hover 120ms | sidebar 内 `panel-entry-btn` click（可扩展 hover 同参数） |
| 浮层定位 | fixed，anchorRef 锚定按钮下方 +6px，窄窗 clamp | 相同：锚定入口按钮，clamp 公式照抄 |
| 头部 | Grid2X2 图标 + 标题 + activePanelLabel chip + 关闭钮 | 相同结构，标题改「面板切换器」 |
| 搜索行 | h-8 圆角输入框，click 打开才 focus | 相同，30ms 延迟 focus 照抄 |
| 置顶区 | `PINNED_LEFT_PANEL_TYPES` 4 列 grid | 相同集合语义（映射到 lite 面板 id） |
| 溢出区 | 3 列紧凑 grid，滚动区 flex-1 min-h-0 | 相同 |
| 底栏 | 当前侧栏 label + 关闭侧栏按钮 | 相同；「关闭侧栏」在 lite 中映射为收起 panel 槽激活面板 |
| 数据源 | `toolSwitcherData.tsx` 静态 + 插件面板 | `slotRegistry.list('panel')` 动态生成 |
| 宿主布局 | ActivityBar + 左侧栏双轨 | polaris-lite 四槽布局 sidebar 槽内单入口 |
| 关闭语义 | mousedown 外部 / Escape / 选中后关闭 | 完全相同 |
| z-index | z-popover（高于内容覆盖层、低于全屏层） | `z-index:50`，需高于 drawer-mask、低于 toasts |

## 6. 实施步骤清单

1. **数据适配**：新建 `src/core/panelNav.ts`——从 `host.slots.list('panel')` + `host.getManifest()` 生成 `PanelNavItem[]`（id/icon/label/description/group/active/onSelect），提供 `usePanelNavItems()` 订阅 registry 变化。
2. **组件实现**：新建 `src/core/PanelSwitcher.tsx`，按上文骨架实现入口按钮 + 浮层；移植 ToolSwitcher 的锚定 effect、搜索过滤、mousedown/Escape 关闭、click 才 focus 搜索框三个行为。
3. **状态接线**：在 SlotLayout（或 navStore）中维护 `activePanelId`；`onSelect` 更新 active 并转发给 panel 槽的 Tab 选择逻辑（`SlotOutlet` 的 `activeIdx` 需要提升或改由事件驱动）。
4. **挂载**：在 `SlotLayout` 的 `shell-sidebar` 内、`SlotOutlet slot="sidebar"` 之前插入 `<PanelSwitcher />`；会话列表保持原位。
5. **样式**：`styles.css` 增加 `.panel-nav-root/.panel-entry-btn/.panel-switcher-menu/.switcher-*/.tool-item` 系列类，全部使用现有 CSS 变量（--bg-panel/--border/--accent 等），不引入硬编码色。
6. **移动端**：≤768px 时入口按钮并入 topbar，浮层改为全宽底部抽屉（复用 `drawer-open` 思路）。
7. **验证**：模拟 10+ 面板注册，检查置顶 4 列、溢出滚动、搜索过滤、Escape/外点关闭、选中后入口 label 更新；跑 `tsc`/构建确认类型通过。
