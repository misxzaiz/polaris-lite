# 面板导航 10 方案探索总纲（brief-nav10）

> 参考对象：**只参考 Polaris 顶部 ToolSwitcher**（搜索行 / 置顶 4 列 grid / 溢出列表 / 底部「当前侧栏」栏 / hover 120ms 开 300ms 收）。
> 不再使用「侧栏栏」概念。目标：为「左侧面板导航」产出 **10 种不同交互方案**，供用户选择一个落地为可交互 HTML 原型。

## 现状

- 左侧栏当前结构：品牌 → 面板 tab/列表 → 会话列表。面板多时挤压。
- 已有参考实现：`src/components/Layout/ToolSwitcher.tsx`（搜索 + 置顶 grid + 溢出列表 + 当前侧栏底栏）。

## 10 种方案（每个必须差异明显）

| # | 代号 | 核心交互 |
|---|------|----------|
| N1 | ToolSwitcher 浮层 | 平时左侧只显示当前面板一个入口，点击弹出 ToolSwitcher 式浮层（搜索+置顶 grid+列表）选择面板 |
| N2 | 常驻高密度列表 | 左侧常驻「搜索 + 置顶 grid + 全量列表」，信息密度对齐 ToolSwitcher，直接点选 |
| N3 | 命令面板式 | 左侧为「命令面板」（Ctrl+K 风格）：搜索框 + 模糊匹配结果列表，回车即切；面板多时靠搜索而非罗列 |
| N4 | 顶部横滚条 | 面板导航放消息区顶部横向滚动条（chip 排布），左侧栏只留会话列表 |
| N5 | 图标 rail + 抽屉 | 最左 48px 图标 rail（每面板一图标），点击展开 240px 抽屉列出该面板详情；面板多时 rail 可滚动 |
| N6 | 树形折叠 | 左侧树形：分组 → 面板，全部展开可滚动；支持拖拽排序（原型可简化） |
| N7 | 分屏 Tab 条 | 左侧上方为横向 Tab 条（可滚动），下方为当前面板内容预览；Tab 多时左右滚动 + 下拉 |
| N8 | 收藏优先 | 左侧只显示「收藏/置顶」（上限 6）+ 「全部面板」按钮弹出完整列表；强调少而精 |
| N9 | 时间线/最近使用 | 按「最近使用」排序的面板流（像历史记录），前面板自动排前；支持搜索与置顶固定 |
| N10 | 混合：搜索+分类 chips | 顶部搜索 + 分类 chips 横向过滤 + 下方紧凑列表； chips 可叠加多选 |

## 硬性要求

1. 每个方案必须给出：交互结构图（文字）、HTML 骨架、10+ 面板时的表现、优缺点、与 ToolSwitcher 的异同。
2. 全部基于 ToolSwitcher 的视觉语言（bg-elevated、搜索行、grid、底栏）。
3. 输出到 `docs/nav10-schemes/N1..N10.md`。

## 评审

2 评委按 4 维度打分：A 信息架构 40% / B 交互体验 30% / C 实现可行性 20% / D 视觉一致 10%。
