# N8 · 收藏优先（Favorite-First）

> 代号 N8。核心交互：左侧只显示「收藏/置顶」面板（上限 6 个）+ 一个「全部面板」按钮；点击后者弹出 ToolSwitcher 式浮层（搜索 + 置顶 grid + 溢出列表 + 底栏）选择其余面板。强调「少而精」，日常 90% 的操作只发生在收藏区。

---

事件顺序：
1. 用户点击 `panel-fav-trigger` → `setAllPanelsOpen(true)`；
2. 浮层挂载，`openMode='click'` → 30ms 后 focus 搜索框；`document.mousedown` 监听外部点击、`keydown Escape` 关闭（与 ToolSwitcher 一致）；
3. 选中任一面板 → `onSelect()` + 关闭浮层 + 该面板写入收藏使用记录；
4. 收藏区支持右键 / 长按「取消收藏」，收藏不足 6 个时显示空位占位（`is-empty` 虚线格）。

## 3. 10+ 面板时的表现与数据流

- **收藏区恒定 6 格**：无论总面板数是 10 还是 50，左栏收藏区面积不变；第 7 个起一律进浮层。认知负担 O(1)。
- **数据流（单向）**：
  1. 数据源 `panels: ToolSwitcherItem[]` 与 `favorites: string[]`（面板 id 有序数组，≤6，超出截断）；
  2. `favorites` 持久化到 kv / localStorage（key 如 `polaris.panelFavorites`），首次进入时若无记录，用 ToolSwitcher 的 `PINNED_LEFT_PANEL_TYPES`（files/git/browser/terminal）作默认收藏；
  3. 收藏区渲染 `favorites.map(id => panels.find(p => p.id === id))`；面板被卸载/禁用时从 favorites 剔除并回填；
  4. 浮层内仍按 `PINNED_LEFT_PANEL_TYPES` 分「置顶 grid + 溢出列表」两层，与收藏无关——即浮层逻辑与现 ToolSwitcher 完全同构，仅多一个「收藏/取消收藏」入口（列表项 hover 出现 ★ 切换钮）；
  5. `onSelect` 后上报使用频次（仅内存计数即可），频次可后续用于「智能推荐收藏」。
- **10+ 面板压力测试**：搜索命中同时作用于收藏区与浮层（收藏区也过滤，避免「收藏了但搜不到」的割裂感）；浮层滚动区 `min-h-0 flex-1 overflow-y-auto`，50 个面板也只滚一个容器。

## 4. 优缺点

**优点**
1. 日常路径最短：常用面板零搜索、零滚动，一次点击直达，且左栏视觉极简；
2. 完全复用 ToolSwitcher 的浮层结构（搜索/grid/底栏），新增代码量最小、视觉一致性最高；
3. 收藏上限形成稳定的空间预期：左栏高度可预测，不会随面板数增长而挤压会话列表。

**缺点**
1. 收藏是强主张：用户必须做「哪些值得收藏」的决策，冷启动体验依赖默认收藏是否贴合其工作流；
2. 非收藏面板多一跳（先开浮层再点选），偶尔用第 8、9 个面板的用户会感到繁琐；
3. 收藏与浮层内置的「置顶 grid」语义重叠（两套「常用」概念），需在文案上区分「我的收藏」与「系统置顶」，否则困惑；
4. 需要处理收藏项失效（面板插件被禁用/卸载）的回填与提示。

## 5. 与 ToolSwitcher 的异同对照表

| 维度 | ToolSwitcher（参考实现） | N8 收藏优先 |
|---|---|---|
| 存在形态 | 纯浮层，无常驻区 | 常驻收藏区 + 浮层 |
| 触发方式 | activityBar 图标 / 顶部按钮，click 或 hover | 左栏「全部面板」按钮，click |
| 搜索 | 浮层内搜索行 | 浮层内搜索行（同构保留） |
| 置顶 grid | `PINNED_LEFT_PANEL_TYPES` 固定 4 项 | 浮层保留系统置顶；左栏另设用户收藏（≤6） |
| 溢出列表 | 3 列紧凑 grid | 同左，另加收藏/取消收藏操作 |
| 底栏 | 当前侧栏 + 关闭侧栏 | 完全一致 |
| 高度策略 | `max-height: min(70dvh,…)` | 浮层一致；收藏区固定 6 行 |
| 定位 | anchorRef 锚定 + 窗口 clamp | 同左（复用锚定逻辑） |
| 新增概念 | — | favorites 状态 + 持久化 + 空位占位 |

## 6. 实施步骤清单

1. 在 `polaris-lite` 侧栏 slot 组件中新增 `PanelFavorites` 组件，定义 `favorites: string[]` 状态与 `toggleFavorite(id)`、`reorderFavorites`（可后置）；
2. 持久化：读写 `localStorage['polaris.panelFavorites']`，初始化默认值取 `PINNED_LEFT_PANEL_TYPES` 与现有面板 id 的交集；
3. 渲染收藏列表（≤6），实现 `panel-fav-item` 的 active/hover/empty 三态与「取消收藏」按钮（hover 显现）；
4. 实现 `panel-fav-trigger` 按钮，绑定 `aria-expanded` 与浮层开关；
5. 抽取/复制 ToolSwitcher 为 `PanelAllPopover`（polaris-lite 内独立实现，去掉 i18n 与 anchorRef 中 Tauri 相关依赖），保留搜索、pinned grid、overflow grid、底栏四段结构；
6. 在浮层列表项上加收藏切换（hover 显示 ★/☆），点击不冒泡、不关闭浮层；
7. 无障碍与键盘：浮层内 Escape 关闭、外部 mousedown 关闭、`role=listbox/option`、选中后焦点归还触发按钮；
8. 自测清单：收藏 6 个 + 新收藏第 7 个（应提示替换或忽略）、取消全部收藏、面板被禁用后收藏回填、搜索同时过滤两层、移动端 ≤768px 时浮层宽度 `min(360px, calc(100vw-16px))`。
