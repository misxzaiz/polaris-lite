# N6 · 树形折叠导航（左侧面板导航方案）

> 对应总纲：`docs/nav10-schemes/brief-nav10.md` 路线 N6。
> 参考实现：`D:\space\base\Polaris\src\components\Layout\ToolSwitcher.tsx`（视觉语言：搜索行、grid、底栏、三级文字色）、`src/core/SlotLayout.tsx`（四槽壳与移动端抽屉状态机）。
> 与 sidebar-schemes S3（可滚动分组 + 置顶收藏）的区别：S3 是「分组头 + 平铺条目」两层；N6 是真正的**树**（分组 → 子分组 → 面板，任意层级），全部展开时可滚动，并内置拖拽排序（原型做简化版：同层内拖动换位）。

---

## 0. 一句话方案

左侧栏改为**树形导航**：根级是「分组」（如 上下文 / 运行 / 集成 / 系统，语义对齐 ToolSwitcher 的 `ToolGroupId`），分组下可再嵌套子分组，叶子节点是面板；每个节点可折叠/展开，全部展开时整树纵向滚动。树支持拖拽排序与跨组移动（原型简化为同层拖拽 + HTML5 DnD），搜索时自动展开命中路径并高亮过滤。

## 2. 状态模型与数据流

### 2.1 状态所有权

| 状态 | 所有者 | 说明 |
|---|---|---|
| `tree` | 新组件 `PanelTree` 内部（由 slots.list 派生 + 用户排序覆盖） | 结构单一权威；插件注册表变化时 merge，不覆盖用户排序 |
| `expandedIds: Set<string>` | PanelTree | 折叠状态；含激活面板的组强制展开 |
| `activePanelId` | shell 级 context（单一权威，同 S1/S3 结论） | 树叶子、右侧 panel 槽共同消费 |
| `query` | PanelTree | 搜索词；非空时强制展开命中路径 |
| `draggingId / dropTarget` | PanelTree（临时态） | DnD 进行中的暂存，drop 后清除 |

### 2.2 树的构建与合并

```
slots.list('panel') 变化
  → 按 manifest.group（缺省 'system'，对齐 ToolSwitcher.getToolGroup 的语义）
    构建默认树：group → 面板叶子（(order ?? 0) 稳定排序）
  → 与持久化的用户排序/重命名 merge：用户移动过的节点以持久化父级为准，
    新插件按 order 插入默认组
  → 计数 badge = 组内叶子数（递归含子组）

搜索 query 变化
  → 过滤：叶子 label/id/description 命中则保留；父链上全部组自动展开
  → 无命中组整组隐藏；全空显示「没有匹配结果」（对齐 ToolSwitcher 空态文案）

点击叶子
  → setActivePanelId(id) → panel 槽只渲染该面板
  → 树上该叶子高亮，祖先链保持展开

拖拽 drop
  → 树不可变更新（同层 move；跨组为增强项）
  → 持久化 { expandedIds, treeOrder } → cap.config（落地）/ localStorage（原型）
```

### 2.3 持久化

- key：`polaris.tree.prefs.v1`，内容 `{ version:1, expandedIds:[], order:{ parentId: [childId…] } }`。
- 原型写 localStorage；宿主落地统一走 `cap.config`（对齐 sidebar-schemes README 前置条件 2）。

## 4. 10+ 面板时的表现与数据流

**表现**：

1. **折叠消化数量**：12~20 个面板分布在 4~6 个组里，默认只展开「含激活面板的组」与第一个组，其余折叠；滚动区高度 = 展开节点数 × 30px + 组头数 × 30px，恒在容器内滚动，**不挤压会话列表**（会话列表是 sidebar 槽的固定底部区块）。
2. **计数 badge 定位**：折叠时组头右侧 `(N)` 计数让用户知道组内规模，不必展开确认。
3. **搜索优先于罗列**：面板 >15 个时，主路径从「展开找」转为「搜索命中」——输入即过滤 + 自动展开命中路径，等价于把 ToolSwitcher 的搜索能力移植进树。
4. **拖拽整理**：用户可把高频面板拖到第一个组置顶，或把临时面板拖进「归档」组；排序持久化后每次启动保持。
5. **深度控制**：原型允许任意嵌套，但 UI 上缩进每层 16px，建议产品约束 ≤3 层（分组 → 子组 → 面板），超过 3 层的 manifest.group 用 `.` 约定映射（如 `integrations.im.mail`）。

**数据流**（一次典型交互）：

```
初始化
  slots.list('panel') → 构建默认树（group 缺省 'system'）
  读 prefs（expandedIds/order）→ merge → 首帧渲染
  含 activePanelId 的祖先链强制加入 expandedIds

用户搜索 "git"
  query='git' → 树过滤：保留「变更/Git」叶子及其祖先链
  → 祖先组自动展开（expandedIds 并入），其余组保持原状但被过滤隐藏
  → 命中叶子高亮子串（<mark>）

用户拖拽「终端」从「运行」到「系统」组末尾（增强项；原型先做同层）
  dragstart(terminal) → dragover(system 组头, 判定 into)
  → drop：tree 不可变更新，terminal.parentId='system'
  → expandedIds 增加 'system'（拖入的组自动展开）
  → 持久化 order

插件热更新新增面板 Y（group: 'run'）
  → 默认树重算 → 与用户 order merge → Y 落到「运行」组 order 位次
  → 若「运行」组展开，Y 立即可见；badge 计数 +1
```

**移动端（≤768px）**：

- 树整体在 `.shell-sidebar` 抽屉内（复用 `setDrawer`/`useDrawer` 与 `.drawer-mask`），选中叶子后收抽屉。
- 触摸端拖拽降级：长按行进入「排序模式」，行尾出现 ↑↓ 按钮，点击与相邻行交换；原型阶段可只做桌面 HTML5 DnD，移动端隐藏把手。
- 极窄屏（≤360px）：组头计数 badge 保留，叶子行 `☆` 置顶钮与拖拽把手合并为一个「⋮」菜单以省宽度。

## 5. 优缺点

### 优点

1. **信息架构最可扩展**：分组 + 任意嵌套天然容纳几十个面板；折叠使「可见条目数」与「面板总数」解耦，滚动长度可控（A 维度强）。
2. **找得到也放得下**：搜索过滤 + 自动展开命中路径，兼顾「浏览型」与「目标型」两种查找方式；计数 badge 提供规模感。
3. **用户可整理**：拖拽排序/归档让用户建立自己的心智模型，长期使用成本随熟悉度下降；排序持久化后体验稳定。
4. **与 ToolSwitcher 视觉同源**：搜索行、计数 chip、底栏、三级文字色直接对齐；分组语义可复用其 `ToolGroupId`（context/changes/run/integrations/developer/system），迁移心智一致。

### 缺点

1. **实现复杂度最高**：递归树渲染、折叠动画、DnD、用户排序与注册表 merge，四件事叠加；原型 JS 量约为 N5 的 1.5 倍，回归面大。
2. **拖拽在触摸端成本高**：HTML5 DnD 移动端体验差，需要长按 + 箭头按钮的降级方案，等于做两套交互。
3. **折叠层级深时点击路径变长**：三层嵌套下到达一个叶子要点 2~3 次展开（虽有「激活链自动展开」缓解）；对比 N2/N3 直接点选更慢。
4. **排序持久化与插件更新冲突**：新插件插入位置、被删除插件遗留的 order 脏数据都需要 merge 策略，边界情况多（需 like S1 的「新插件按 order 落默认组」规则兜底）。

## 6. 与 ToolSwitcher 的异同对照表

| 维度 | ToolSwitcher（Polaris 顶部） | N6 树形折叠 |
|---|---|---|
| 信息结构 | **两层平铺**：置顶 4 列 grid + 溢出 3 列 grid，`group` 仅用于搜索命中与语义归类 | **真树**：分组 →（子分组）→ 面板，任意嵌套、可折叠 |
| 面板多时策略 | 溢出区 3 列 grid 一屏罗列 + 搜索兜底 | 折叠 + 纵向滚动 + 搜索展开命中路径 |
| 搜索行 | 有：过滤 label/description/group，空态「没有匹配结果」 | 有：同款样式与过滤字段，额外自动展开祖先链 |
| 置顶机制 | `PINNED_LEFT_PANEL_TYPES` 硬编码 4 个置顶进 grid | 无硬编码置顶；置顶 = 用户拖拽到首组（或 ☆ 标记，原型简化） |
| 排序 | 固定（pinned 优先，其余按传入顺序） | 用户可拖拽排序并持久化 |
| 底栏 | 「当前侧栏： X + 关闭」 | 同款「当前面板: X」，另加「全部折叠」工具钮 |
| 打开/关闭 | 浮层：click/hover 打开、Esc/外点关闭 | 常驻侧栏，无开合生命周期 |
| 激活态 | `item.active` → `bg-primary/10 text-primary` | 叶子 `.active` 同款 accent-soft + 左缘指示条，祖先链强制展开 |
| 数据来源 | `ToolSwitcherItem[]` props | `host.slots.list('panel')` + manifest.group 派生树 + 用户排序 merge |
| 交互粒度 | 一次点击直达面板 | 分组折叠一次点击；叶子一次点击；深层叶子需先展开祖先 |
